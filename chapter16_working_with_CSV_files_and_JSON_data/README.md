# Chapter 16 – Working with CSV Files and JSON Data 📊📦

## Topics Covered
- Reading CSV files with the csv module  
- Writing CSV files and controlling delimiters  
- Using DictReader and DictWriter  
- Removing headers and processing rows automatically  
- Understanding JSON structure (objects and arrays)  
- Converting JSON to Python objects with json.loads()  
- Converting Python objects to JSON with json.dumps()  
- Consuming web APIs and parsing JSON responses  

## Goal
Automate repetitive tasks involving structured data, such as processing spreadsheets exported as CSV, transforming datasets, retrieving information from web services, and extracting specific fields from large JSON responses.

## Notes
CSV and JSON are two of the most common data formats in real-world automation and backend workflows.  
CSV is widely used for tabular data exchange between systems, while JSON is the standard format for APIs and web services.
