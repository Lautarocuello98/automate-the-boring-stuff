# Chapter 13 – Working with Excel Spreadsheets 📊

Scripts from **Chapter 13: Working with Excel Spreadsheets**.

## Topics Covered
- Reading Excel files with openpyxl  
- Writing data to Excel files  
- Creating and modifying worksheets  
- Accessing rows, columns, and cells  
- Formatting cells (fonts, styles)  
- Automating spreadsheet calculations  

## Goal
Automate repetitive tasks involving Excel files, such as reading structured data, generating reports, and creating formatted spreadsheets programmatically.

## Notes
Working with spreadsheets is a core automation skill because many real-world workflows depend on Excel for storing and processing structured data.

This chapter focuses on using **openpyxl** to interact with `.xlsx` files, including reading datasets, generating tables, and formatting output.

## Projects

multiplication_table.py  (Creates an NxN multiplication table and saves it as a formatted Excel spreadsheet.)

blank_row_inserter.py (Inserts blank rows into an Excel spreadsheet automatically.)

spreadsheet_cell_inverter.py (Swaps rows and columns by transposing an Excel worksheet.)

text_to_spreadsheet.py (Reads multiple text files and writes their contents into an Excel spreadsheet.)

spreadsheet_to_text.py (Reads an Excel spreadsheet and writes the contents into multiple text files.)
